# Student Management System

## Project Description
The Student Management System is a console-based application developed using Python. It allows users to manage student records through a menu-driven interface.

## Features
- Add a new student
- View all students
- Search a student by ID
- Update student details
- Delete a student
- Store student records in a CSV file
- Load student records automatically when the program starts

## Technologies Used
- Python
- CSV File Handling

## Python Concepts Used
- Functions
- Lists
- Dictionaries
- Loops
- Conditional Statements
- File Handling

## How to Run
1. Download or clone the repository.
2. Open `student_management.py` in VS Code.
3. Run the program.
4. Use the menu to manage student records.

## Sample Menu
```
===== STUDENT MANAGEMENT SYSTEM =====
1. Add Student
2. View Students
3. Search Student
4. Update Student
5. Delete Student
6. Exit
```
